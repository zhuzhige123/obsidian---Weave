## 日本語ドキュメント

### プラグイン紹介

Obsidian Weave プラグインシリーズには、Weave Deck、Weave EPUB Reader、Weave Incremental Reading の **3 つのみ** が含まれます。このシリーズは Obsidian 専用に作られ、Obsidian 内での長期学習のために生まれました。

Weave Deck はシリーズの中核プラグインで、機能が最も豊富で適用範囲も最も広いです。Obsidian の Markdown 内容から記憶カードを生成し、独立した deck ファイルに保存することで、元のノートを汚さずに集中管理できます。生成された溯源リンクで元の文脈に戻り、関連フィルターでそのドキュメントから生成された重要な記憶カードや抜粋カードを表示できます。また、生成した各種問題カードを試験にまとめてテストすることも可能で、記憶の定着と習得度の検証に役立ちます。

最低 Obsidian バージョン：**1.7.0**

**抜粋 → カード作成 → FSRS6 復習 → テスト検証 → 溯源・再構成** の学習ループを中心に設計されています。カードと元ノートは分離保存され、復習やテスト中も原文の文脈に戻れます。

### 公開 API（サードパーティ連携）

Weave は他の Obsidian プラグイン向けに **WeaveDomainAPI** を `app.plugins.plugins["weave"].getOfficialAPI()` 経由で公開しています。API 経由でカードとデッキを書き込んでください — Vault 内の `.wdeck` / `.qbank` ファイルを**直接**編集しないでください。

主な機能：

- **記憶カード**：`createCard` で単一カード作成；`importCards` で一括インポート（`ensureDeck` による自動デッキ作成、重複スキップ対応）
- **記憶デッキ**：`createDeck` で新規作成；`listDecks` / `findDeck` でクエリ；`updateDeck` / `deleteDeck` でメンテナンス
- **一括操作**：`moveCards` で一括移動（復習進捗を保持）；`deleteCards` で一括削除；`updateCardContent` で本文のみ修正
- **試験問題バンク**：`createQuestionBank` で新規作成；`addCardsToQuestionBank` で既存カードを参照追加；`importExamQuestions` で記憶デッキに一括書き込みしてバンクに紐付け（AI 出題に適する）
- **連携前の確認**：`getInfo()` が `apiVersion` と `capabilities` を返す — 未公開フィールドを前提にしないでください

連携説明は開発ドキュメント `docs/WEAVE_OFFICIAL_API_GUIDE.md`（型の真源：`src/services/weave-domain/types.ts`）を参照してください。

### インストール

#### 方法 1：コミュニティプラグイン（推奨）

1. **設定 → コミュニティプラグイン → 閲覧** を開く（必要に応じて「制限モード」をオフ）
2. **Weave Deck** を検索し、インストールして有効化

#### 方法 2：手動インストール

1. `main.js`、`manifest.json`、`styles.css` を `.obsidian/plugins/weave/` にコピー
2. **Legacy APKG インポート**が必要な場合は `sql-wasm.wasm` も追加
3. Obsidian を再起動してプラグインを有効化

### クイックスタート

1. サイドバーから Weave Deck ビューを開き、カードライブラリを初期化（`weave/memory/` など）
2. 任意：AI カード作成用に OpenAI 互換 API を設定
3. Markdown または EPUB から抜粋し、記憶カードを作成して復習を開始
4. 任意：カード管理をサイドバーに配置し、「現在のアクティブドキュメントに関連付け」をオンにして、ノート執筆中に蓄積したカードを確認

### データと同期

**同期推奨（Vault 内）**：`weave/memory/`（`.wdeck`）、`weave/question-bank/`（`.qbank`）、関連 Markdown と添付ファイル。

**通常は端末間同期不要**：`.obsidian/plugins/weave/` 下のキャッシュとローカル状態。複数端末での学習は Vault 内容の同期を優先してください。

⚠️ 影響を理解していない限り、`.wdeck` / `.qbank` ファイルを一括でリネームまたは削除しないでください。

### プライバシーとネットワーク

- 学習データは**デフォルトでローカル Vault に保存**され、ライブラリ内容は自動アップロードされません。
- **プレミアムサポートの激活**はライセンスサービスにアクセスする場合があります。詳細はリポジトリのプライバシー説明を参照してください。
- **AI 機能**は自己設定のサードパーティ API を呼び出します；**APKG** は旧カードパックのオフラインインポート / デッキエクスポート用で、本機の Anki 常時接続には依存しません。

### よくある質問

#### 1. EPUB リーダーや漸進的読書との関係は？

**Weave は単独で利用可能**です：Markdown でのカード作成、FSRS 復習、問題バンクなどに他プラグインのインストールは必須ではありません。[Weave EPUB Reader](https://github.com/zhuzhige123/obsidian-weave-reader) をインストールすると、書籍内で抜粋・カード作成し、書籍アンカーで原文に戻れます；漸進的読書は読書キューと章のスケジューリングを担当します。リーダーのプレミアムサポートは Weave のライセンスと連動する場合があります。三者は**役割分担で協力**し、必要に応じてインストールしてください。

#### 2. カードと抜粋は全プラットフォームで同期できますか？

**はい。** カードライブラリと関連ノートは Vault 内にあり、Obsidian Sync、iCloud、クラウドドライブなど Vault 同期方式によりデスクトップとモバイルで一致します（[データと同期](#データと同期) を参照）。

#### 3. データのエクスポート / バックアップは可能ですか？

**はい。** デッキを **APKG** にエクスポートできます；`.wdeck`、`.qbank` および関連 Markdown もライブラリ内にあり、手動コピーやプラグインのデータ管理によるバックアップも可能です。**データは完全にローカル**で、バックアップ戦略はご自身で管理します。

#### 4. なぜプレミアムサポートがあるのですか？

**継続的な開発を支援**するためで、チームが長期的に復習とテストの細部を磨き続けられます。**基本体験は無料**で、FSRS 復習、多形態カード、溯源、AI カード作成（自前 API）、テーブルビュー、ドキュメントクイズ、記憶デッキの「記憶保持率」分析、公開 API によるカード/デッキ作成・一括インポート、APKG 相互運用など中核の学習ループをカバーします；残りの記憶デッキ分析チャート、グリッド / マソンリー / Kanban / タイムライン、エマージェントデッキ、試験問題バンクとその分析、Markdown 埋め込み、段階的穴埋めなどは必要に応じてプレミアムサポートを有効化してください。

#### 5. サブスクリプションですか、買い切りですか？

**買い切り制**（一度の有効化で長期利用）で、月額サブスクリプションではありません。

#### 6. どの UI 言語が利用できますか？

**Weave は機能モジュールが多く、UI 文言量も大きい**ため、完全なローカライズには継続的な投入が必要です。**現在利用可能な UI 言語**は簡体字中国語、英語、ロシア語、日本語、韓国語です；**ドイツ語、フランス語、スペイン語などは順次追加**されます。ご理解のほどよろしくお願いいたします。
