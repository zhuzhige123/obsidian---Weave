## Документация на русском

### О плагине

Серия плагинов Obsidian Weave включает Weave Deck, Weave EPUB Reader и Weave Incremental Reading — **ровно три** плагина, и только их. Серия полностью ориентирована на Obsidian и создана для долгосрочного обучения внутри Obsidian.

Минимальная версия Obsidian: **1.7.0**

### Публичный API (интеграция сторонних разработчиков)

Weave предоставляет другим плагинам Obsidian **WeaveDomainAPI** через `app.plugins.plugins["weave"].getOfficialAPI()`. Записывайте карточки и колоды через API — **не** редактируйте файлы `.wdeck` / `.qbank` в Vault напрямую.

Основные возможности:

- **Карточки памяти**: `createCard` для одной карточки; `importCards` для массового импорта (поддержка `ensureDeck` для автосоздания колоды, пропуск дубликатов)
- **Колоды памяти**: `createDeck` для создания; `listDecks` / `findDeck` для запроса; `updateDeck` / `deleteDeck` для обслуживания
- **Массовые операции**: `moveCards` (сохраняет прогресс повторения); `deleteCards`; `updateCardContent` только для содержимого
- **Экзаменационные банки**: `createQuestionBank`; `addCardsToQuestionBank` для ссылки на существующие карточки; `importExamQuestions` для массовой записи карточек памяти и привязки к банку (удобно для экзаменов, сгенерированных ИИ)
- **Перед интеграцией**: `getInfo()` возвращает `apiVersion` и `capabilities` — не предполагайте неопубликованные поля

Инструкции по интеграции см. в `docs/WEAVE_OFFICIAL_API_GUIDE.md` (источник типов: `src/services/weave-domain/types.ts`).

### Экосистемная совместная работа (опционально)

Помимо возможностей самого Deck, можно расширить источники чтения и создания карточек с помощью других плагинов серии и инструментов сообщества.


| Плагин / возможность | Роль |
| --- | --- |
| [Weave EPUB Reader](https://github.com/zhuzhige123/obsidian-weave-reader) | Погружённое чтение, выдержки для карточек, переход по якорям книги |
| Инкрементальное чтение (экосистема Weave) | Очередь чтения и планирование глав |
| PDF++, Excalidraw, Media Extended, Mind Map и др. | Подключение PDF, рисунков, временных меток видео и ментальных карт к тому же циклу повторения |

### Установка

#### Способ 1: Плагины сообщества (рекомендуется)

1. Откройте **Настройки → Плагины сообщества → Обзор** (при необходимости отключите «Ограниченный режим»)
2. Найдите **Weave Deck**, установите и включите

#### Способ 2: Ручная установка

1. Скопируйте `main.js`, `manifest.json`, `styles.css` в `.obsidian/plugins/weave/`
2. При необходимости **Legacy APKG import** добавьте `sql-wasm.wasm`
3. Перезапустите Obsidian и включите плагин

### Быстрый старт

1. Откройте представление Weave Deck на боковой панели и инициализируйте библиотеку карточек (`weave/memory/` и т. д.)
2. Опционально: настройте OpenAI-совместимый API для создания карточек ИИ
3. Сделайте выдержку из Markdown или EPUB, создайте карточки памяти и начните повторение
4. Опционально: разместите управление карточками на боковой панели и включите «Связать с активным документом», чтобы при написании заметок видеть уже накопленные карточки

### Данные и синхронизация

**Рекомендуется синхронизировать (в Vault)**: `weave/memory/` (`.wdeck`), `weave/question-bank/` (`.qbank`), связанные Markdown и вложения.

**Обычно не требует синхронизации между устройствами**: кэш и локальное состояние в `.obsidian/plugins/weave/`. Для обучения на нескольких устройствах в первую очередь синхронизируйте содержимое Vault.

⚠️ Не переименовывайте и не удаляйте файлы `.wdeck` / `.qbank` массово, если не понимаете последствий.

### Конфиденциальность и сеть

- Данные обучения **по умолчанию хранятся локально в Vault** и не загружаются автоматически.
- **Активация расширенной поддержки** может обращаться к сервису лицензий; подробности — в описании конфиденциальности репозитория.
- **Функции ИИ** используют настроенный вами сторонний API; **APKG** — для офлайн-импорта старых колод / экспорта колод, без постоянного подключения к Anki на этом компьютере.

### Часто задаваемые вопросы

#### 1. Как это связано с EPUB Reader и инкрементальным чтением?

**Weave можно использовать автономно**: создание карточек в Markdown, повторение FSRS, банки вопросов — без обязательной установки других плагинов. После установки [Weave EPUB Reader](https://github.com/zhuzhige123/obsidian-weave-reader) можно делать выдержки в книгах, создавать карточки и переходить по якорям книги к исходному тексту; инкрементальное чтение отвечает за очередь чтения и планирование глав. Расширенная поддержка читалки может быть связана с лицензией Weave по правилам продукта. Три плагина **дополняют друг друга** — устанавливайте по необходимости.

#### 2. Синхронизируются ли карточки и выдержки на всех платформах?

**Да.** Библиотека карточек и связанные заметки находятся в Vault и остаются согласованными на настольных и мобильных устройствах через Obsidian Sync, iCloud, облачные диски и другие способы синхронизации Vault (см. [Данные и синхронизация](#данные-и-синхронизация)).

#### 3. Можно ли экспортировать / резервировать данные?

**Да.** Колоды можно экспортировать в **APKG**; `.wdeck`, `.qbank` и связанный Markdown также находятся в библиотеке — можно копировать вручную или использовать резервное копирование в управлении данными плагина. **Данные полностью локальны** — стратегию резервного копирования определяете вы.

#### 4. Зачем нужна расширенная поддержка?

Она **поддерживает непрерывную разработку**, чтобы команда могла долгосрочно совершенствовать детали повторения и тестирования. **Базовый опыт бесплатен** и охватывает повторение FSRS, разные типы карточек, трассировку, создание карточек ИИ (свой API), тест по документу, аналитику «удержание памяти» для колод памяти, публичный API для создания карточек/колод и массового импорта, обмен APKG и другие элементы основного цикла обучения; остальные аналитические диаграммы колод памяти, сетка / masonry / Kanban / Timeline, эмерджентные колоды, экзаменационные банки и их аналитика, встраивание Markdown, прогрессивные пропуски и т. д. можно включить по необходимости через расширенную поддержку.

#### 5. Подписка или разовая покупка?

**Разовая покупка** (одна активация, длительное использование), не ежемесячная подписка.

#### 6. Какие языки интерфейса поддерживаются?

**Weave имеет обширный функционал и большой объём текстов интерфейса** — полная локализация требует постоянных усилий. **Сейчас доступны** упрощённый китайский, английский, русский, японский и корейский; **немецкий, французский, испанский и другие языки будут добавляться постепенно**.
